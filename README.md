# なにわセレクトショップ

大阪の特産品・名産品をテーマにした EC サイトです。  
就職活動用のポートフォリオとして、公開可能な形に整備しています。

## デモ

- 公開 URL: https://select-shop-ec.vercel.app/
- 管理画面: https://select-shop-ec.vercel.app/admin/login

※ 管理画面はアカウントが必要です。デモ用アカウントは面接前にメールにてご案内する想定です。

## 作品概要

ユーザーが商品を閲覧し、カートに追加し、注文完了まで進めることができます。  
あわせて、管理者が注文確認や商品管理を行うための管理画面も実装しています。

## 主な機能

- 商品一覧表示
- カート追加・数量変更・削除
- 注文完了画面の表示
- 管理者ログイン
- 管理画面での注文一覧確認
- 管理画面での商品管理

## 使用技術

- Next.js 16（React ベース）
- TypeScript
- Supabase
- Resend
- CSS
- Vercel
