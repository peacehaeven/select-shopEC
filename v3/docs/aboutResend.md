# Resend とは？
**Resend** は、開発者向けのメール送信サービスです。
自前のサーバーから直接メールを送信すると、受信側に「迷惑メール」として判定されるリスクが高くなります。Resend のような専門サービスを利用することで、高い到達率を確保できます。

---

## 手順：Resend の登録から設定まで

### ① アカウント作成
1. [resend.com](https://resend.com) にアクセスします。
2. 右上の **[Sign Up]** をクリック（GitHub アカウントでの登録も可能です）。
3. メールアドレスを確認してログインを完了させます。

### ② APIキーを取得
1. ダッシュボードの左メニューから **[API Keys]** をクリックします。
2. **[Create API Key]** ボタンを押します。
    * **Name**: 任意（例: `naniwa-ec`）
    * **Permission**: `Sending access` を選択
3. 作成されたキー（`re_xxxxxxxx...`）をコピーし、`.env.local` に貼り付けます。

```bash
RESEND_API_KEY=re_ここにコピーしたキーを貼る
```

> [!CAUTION]
> **APIキーは作成時の一度しか表示されません。** 作成後、必ずすぐにコピーして保存してください。

### ③ テスト送信（無料・ドメイン不要）
開発中はドメイン登録なしでもテスト送信が可能です。ただし、以下の制限があります。

| 項目 | 内容 |
| :--- | :--- |
| **送信元アドレス** | `onboarding@resend.dev`（固定） |
| **送信先アドレス** | **Resend に登録したメールアドレスのみ** |
| **月の送信上限** | 3,000通まで無料 |

※ 自分以外のチームメンバーに送る場合は、Resend ダッシュボードの「Audiences」や「Domains」にアドレスを追加する必要があります。

> [!TIP]
> この段階では、`.env.local` の `RESEND_FROM` は **コメントアウトか削除** して問題ありません。コード側でテスト用アドレスに自動フォールバックされます。

### ④ 本番用のドメイン設定（任意）
本番公開時に独自のドメイン（例: `naniwa-select.jp`）から送信したい場合の手順です。

1. ダッシュボードの **[Domains]** → **[Add Domain]** をクリック。
2. 所有しているドメインを入力します。
3. 表示された **DNS レコード（TXT・MX）** を、お使いのドメイン管理画面（お名前.comやムームードメインなど）に登録します。
4. 認証が完了したら、`.env.local` に送信元アドレスを設定します。

```bash
RESEND_FROM=なにわセレクトショップ <noreply@naniwa-select.jp>
```

## 今すぐやること（まとめ）

1. **[resend.com](https://resend.com) でアカウント作成**
2. **APIキーを発行** して `.env.local` の `RESEND_API_KEY` に貼り付ける
3. `.env.local` の **`RESEND_FROM` 行を削除**（またはコメントアウト）
4. `npm run dev` で起動して動作確認

**ドメイン設定がなくても、開発・テストは問題なく進められます！**
