# 本番運用時のメール送信設定

## Context
現在はResendのドメイン未検証状態でテスト中。`RESEND_TEST_TO`で送信先を自分のアドレスに固定している。 本番運用時は顧客のメールアドレスに届くよう、送信元ドメインの認証と環境変数の整理が必要。

## 仕組み（現状）

| 環境変数 | 現在の値 | 役割 |
|---|---|---|
| `RESEND_API_KEY` | 設定済み | Resend APIキー |
| `RESEND_TEST_TO` | `25r1116.shimojo@gmail.com` | テスト時の強制送信先（設定するとguestメール無視） |

**コード (`app/api/ship/route.ts:57`) の動作:**
- `RESEND_TEST_TO` が設定されている → そのアドレスに送信（テスト用）
- `RESEND_TEST_TO` が未設定       → `order.guest_email` に送信（本番用）

## 本番移行手順

### Step 1: Resendでドメイン認証
1. resend.com ダッシュボード → Domains → Add Domain
2. 独自ドメイン（例: `naniwa-select.com`）を追加
3. 指示されたDNSレコード（MX/TXT/DKIM）をドメイン管理会社で設定
4. 認証完了を確認

### Step 2: 環境変数を変更
`.env.local`（本番環境では本番用の環境変数設定）:

```env
# RESEND_TEST_TO を削除（またはコメントアウト）→ guest_email 宛に自動的に届く
# RESEND_TEST_TO=25r1116.shimojo@gmail.com  ← この行を削除
```

### Step 3: 送信元アドレスを変更（コード修正）
`app/api/ship/route.ts` の `from` を環境変数化:

```typescript
from: process.env.RESEND_FROM ?? 'naniwa-select@resend.dev',
```

`.env.local`（本番）:

```env
RESEND_FROM="なにわセレクトショップ <noreply@naniwa-select.com>"
```

## 変更ファイル
- `naniwa-ec/app/api/ship/route.ts` — `from` アドレスを環境変数化

## テスト方法
- **テスト環境**: `RESEND_TEST_TO` を設定 → 自分のアドレスに届くことを確認
- **本番環境**: `RESEND_TEST_TO` を削除 → 注文時のメールアドレスに届くことを確認
